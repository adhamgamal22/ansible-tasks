# Ansible Tasks 🚀

A collection of practical **Ansible tasks and exercises** created for learning and practicing Ansible automation.

## 📌 Repository

This repository contains different Ansible tasks, exercises, and automation practices.

Each task is organized in its own directory with the required files and configurations.

## 🛠️ Technologies

* Ansible
* Linux
* YAML
* SSH

### 🧩 Common Components

* 🖥️ **Inventory** — Defines the managed hosts.
* 📜 **Playbooks** — Describe what Ansible should do.
* 📋 **Tasks** — Individual actions to be executed.
* ⚙️ **Modules** — Built-in tools used to perform actions.
* 🔢 **Variables** — Store reusable values.
* 📦 **Roles** — Organize and reuse Ansible configurations.

---

### 🚀 Running Ansible

* **Ping all hosts:**
  ```bash
  ansible all -i inventory -m ping
  ansible-playbook -i inventory playbook.yml

## 🎯 Purpose

The purpose of this repository is to practice **Ansible automation and configuration management** through hands-on tasks.
