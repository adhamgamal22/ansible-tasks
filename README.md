A collection of practical **Ansible tasks and exercises** created for learning and practicing Ansible automation.

## 📌 Repository

This repository contains different Ansible tasks, exercises, and automation practices.

Each task is organized in its own directory with the required files and configurations.

* Ansible
* Linux
* YAML
* SSH

## 🎯 Purpose

The purpose of this repository is to practice **Ansible automation and configuration management** through hands-on tasks.
